# Handwritten Digit Recognizer

CNN built in PyTorch to recognize handwritten digits from the MNIST dataset.

## Results
- Test accuracy: **99.5%**

## What's inside
- CNN with batch normalization, dropout and data augmentation
- Evaluation: confusion matrix, per-class precision/recall, misclassified digits
- Draw-a-digit demo with MNIST-style preprocessing (run in Google Colab)

## How to run
Open the notebook in Google Colab and run all cells.

## Tech
Python, PyTorch, NumPy, Matplotlib, scikit-learn
